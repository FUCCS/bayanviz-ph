# Demo guide

1. Open BayanViz. The dashboard starts without observations.
2. Open API Sources, keep one location and the seven-day default, then Fetch Data and Use Dataset. Alternatively, open Dataset Upload, select a real weather CSV, Parquet, or supported JSON file, and map its columns.
3. For an upload, declare UTC daily dates and click Use Dataset. Switch between fetched and uploaded weather with the Dataset dropdown; inspect each loaded date range and location.
4. Select dates and locations, then Apply Filters to update indicators and climate charts.
5. Open Data Relationships or Geographic Explorer to inspect paired statistics and the point map.
6. Use Show Python Code, Data Interpretation, View Data, and Download to inspect evidence and reproduce results.
7. For integrated analysis, open Multi-Source Manager and choose uploaded or API weather, then uploaded or NASA POWER API solar data.
8. For a solar upload, map its location/date/solar fields and declare reported units and UTC. Click Validate Datasets.
9. Inspect matched dates and missingness before Merge and Analyze. Download the quality report or chart package.
10. Clear My Data to remove temporary uploaded data and results.

Only the five registered point locations are supported. Uploaded records are never presented as national or province-wide observations.
