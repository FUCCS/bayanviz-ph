# Demo guide

1. Open BayanViz. The dashboard starts empty until a source file is uploaded.
2. Open Dataset Upload, select a real weather CSV, Parquet, or supported JSON file, and map its columns.
3. Declare UTC daily dates and click Use Dataset. Inspect the loaded date range and locations.
4. Select dates and locations, then Apply Filters to update indicators and climate charts.
5. Open Data Relationships or Geographic Explorer to inspect paired statistics and the point map.
6. Use Show Python Code, Data Interpretation, View Data, and Download to inspect evidence and reproduce results.
7. For integrated analysis, open Multi-Source Manager and upload a solar file from your source.
8. Map its location/date/solar fields, declare reported units and UTC, then Validate Datasets.
9. Inspect matched dates and missingness before Merge and Analyze. Download the quality report or chart package.
10. Clear My Data to remove temporary uploaded data and results.

Only the five registered point locations are supported. Uploaded records are never presented as national or province-wide observations.
